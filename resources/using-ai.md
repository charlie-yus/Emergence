# AI 用法：选哪个、怎么喂、提示词、Skills 精华

## 一　选哪种 AI

| 类型 | 例子 | 能做的 | 适合 |
|---|---|---|---|
| 能读仓库、能改文件、能运行代码 | Codex（ChatGPT 里的）、Claude Code、Cursor | 直接读这个仓库、改 `PROGRESS.md`、跑数据分析 | 最省事，推荐 |
| 能读文件、能运行代码的网页版 | ChatGPT 网页版（Work 模式） | 上传文献和数据、跑回归、生成表格；改 `PROGRESS.md` 要你自己粘贴 | 全程可用 |
| 只能问答 | 豆包、Kimi、元宝 | 扫盲、改文字、解释概念 | **不能用来处理数据** |

XX老师的建议：要用能在后台处理数据、直接跑回归的模型，如 GPT、Claude；只能问答的工具适合扫盲。
ChatGPT 的开通方法：问 Charlie 要组里的《ChatGPT 使用与订阅教程》。

## 二　怎么把这个仓库交给 AI

- **能读 GitHub 的 AI**：直接发这句话：
  > 「请读我的 GitHub 仓库 https://github.com/【你的用户名】/【仓库名】 ，先读 AGENTS.md，按里面的规则带我做。」
- **打不开链接的 AI**：在仓库页面点绿色的 Code → Download ZIP，解压后把 `AGENTS.md`、`PROGRESS.md`、`workflow/` 里的文件上传给它，再发同一句话。
- **每次开新对话**都这样做。AI 会先读 `PROGRESS.md`，接着上次的进度往下做。

## 三　怎么喂文献

- XX老师的话：“输入的是垃圾，输出的也是垃圾。”**让 AI 自己上网搜，质量远不如喂给它下载好的顶刊全文。**
- 每次上传 5–10 篇 PDF，让 AI 把这几篇填进文献矩阵，再传下一批。
- 读完所有文献后，再让它总结观点、建议假设或框架。

## 四　提示词（XX老师 10-22 会议版，【】换成自己的内容）

1. **找文献**：我要写一篇题为《【题目】》的本科毕业论文。请在 UTD24 和 FT50 期刊中找出与这个主题最相关的 20 篇英文论文，再在《管理世界》《中国工业经济》等中文顶刊（问卷或对策类题目可放宽到 CSSCI、北大核心）中找出 20 篇中文论文。每篇列出标题、作者、期刊、年份、DOI，以及可以从哪个数据库下载全文。只列真实存在的论文，不确定的不要列。
2. **读文献、规划**：附件是我下载的论文全文。请先读完，然后：①总结这一主题的主要观点和常用研究设计；②为我的论文《【题目】》建议研究框架（实证类：三个假设及机制；对策类：分析或诊断框架）；③给出论文结构。
3. **变量和数据**：我的核心变量是【变量】。请告诉我：学界通常用哪些指标测量它；这些数据在 CSMAR（或 CNRDS）的哪个数据库、哪张表、哪些字段，覆盖哪些年份。如果数据库里没有，请给出替代来源，并说明属于“学校已买、公开免费、必须自己做、需要购买”中的哪一类。
4. **规划模型并试跑**：附件是数据和参考文献。请规划回归模型：选合适的控制变量，加入行业和年份固定效应，检验【X】对【Y】的影响。请汇报模型设定、样本量、主要系数、标准误和显著性。必须真实运行，不能估计数字。
5. **机制和条件**：基于主效应结果，再检验一个中介机制和一个调节变量，说明影响通过什么渠道产生、在什么条件下更强或更弱。
6. **按范文写**：附件是一篇范文。请参照它的结构和写法，把我的结果写成【某一章】：推理写清楚，表格规范，标明每处引用的出处。
7. **按学校格式改**：附件是武汉学院本科毕业论文的格式要求。请严格按要求修改，包括标题层级、字体字号、图表编号、参考文献格式，并列出改了哪些地方。
8. **案例论文**：我的题目是《【题目】》。请规划论文结构，建议选哪几家企业做案例（按企业类型各选典型），说明理由和每章写什么。
9. **自我优化**：你刚才给的内容还有优化空间吗？请先站在答辩老师和审稿人的角度给自己提修改意见，再按意见修订一版。（重复 3–8 轮）
10. **文章在哪下载**：《【标题】》（DOI：【DOI】）应该从哪个数据库下载全文？

### Skills 精华（AI 在相应步骤遵守）

**选题与论证**（第 1–3 步）
- 兴趣 ≠ 题目：先划清研究对象、范围和要回答的问题。
- “研究少”≠ 研究空白，“没人做过”≠ 有新意。本科论文不必声称填补空白，讲清“为什么值得研究”即可。
- 相关 ≠ 机制 ≠ 因果；AI 说得很自信，不等于有证据。
- 不知道的地方写“未知”，不要让 AI 补猜。

**审稿人视角**（第 3、10、13 步）
- 依次检查：问题清楚吗？证据配得上结论吗？数字前后一致吗？有没有更简单的解释？对策能落地吗？
- 意见分“必须改”和“可不改”，本科论文只改前者。

**去 AI 味**（第 10、13 步）。改的时候**不改数字、不改引用**。
- 删套话：“在当今时代”“具有重要意义”“综上所述”“值得注意的是”。
- 少用“不是……而是……”和三连排比，不要每段末尾都加一句总结金句。
- 少用破折号，不滥用加粗。
- 一句话只说一件事，用具体的数和例子代替形容词。
- 去掉多余的免责声明和过度谨慎的说法，但必要的研究局限要保留。

**引用核验**（第 2、10、16 步）
- 每条参考文献逐项核对：作者、标题、年份、期刊、卷期、页码、DOI，都要和知网或出版社页面一致。
- 正文中引用的文献和文末列表一一对应，不多也不少。
- 按 GB/T 7714 格式写。
