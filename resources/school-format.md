# 武汉学院本科毕业论文格式要点（文经管类）

**以学校原件 `school-format-original.doc` 为准。**

- 用 LaTeX 排版：模板在素材仓库 https://github.com/charlie-yus/Emergence-assets 的 `skills/wuhan-college-thesis-latex/`，用法见那个仓库的 README。
- 用 Word 排版：先读素材仓库的 `word-tools/layout-rules.md`。这里只列组里第一篇论文排版时核对过、也最容易出错的地方。

## 结构

封面 → 声明 → 中文摘要 → 英文摘要 → 目录 → 引论 → 正文各章（含“讨论”）→ 结语 → 参考文献 → 致谢 → 附录

- 题目不带多余副标题；封面信息建议由【人】在 Word 里手填或逐项核对。

## 页面与页码

- A4 纸。页边距：上 3 cm，下 2.5 cm，左 2.5 cm，右 2 cm。
- 页眉：校名，9 磅，下面加一条横线。
- 页码：
  - 声明页、题名页不印页码；
  - 中文摘要、英文摘要、目录各自从 1 开始编；
  - 正文从 1 开始，一直连续到最后。

## 字体、字号、行距

| 部分 | 字体字号 | 行距 |
|---|---|---|
| 正文 | 中文宋体小四，西文 Times New Roman；首行缩进 2 字符；两端对齐 | 1.25 倍 |
| 正文一级标题 | 16 磅 | — |
| 引论、结语 | 18 磅 | — |
| 摘要、目录、参考文献、附录的标题 | 18 磅，另起一页 | — |
| 关键词 | “关键词”三个字三号加粗，内容小四不加粗；与摘要正文之间空一行 | — |
| 参考文献 | 首行缩进 2 字，续行悬挂缩进 | 单倍 |
| 致谢 | — | 固定值 23 磅 |

- 标题层级：一、→（一）→ 1．→（1）（一级标题加黑）
- 两个字的标题，中间空两个汉字，例如“摘　　要”“目　　录”。
- **跨系统字体名**：Word 文件里必须写 Windows 通用字体名（`宋体`、`黑体`、`楷体`、`仿宋`、`Times New Roman`），不要留 Mac 专属字体名（如 `SimSong`、`Heiti SC`、`华文宋体`）。

## 表格和插图

**表格**
- 三线表（顶线、底线粗，表头下细线，表头加粗）；表题放在**表的上方**，按“表1、表2……”连续编号。
- 表格中重复的分类列（例如变量定义表的“变量类型”）要**纵向合并单元格**。
- **删掉多余项**：不要写“资料来源：作者自行整理”和无意义的“计量单位”行；确有外部来源的注明具体数据库或文件。
- 跨页的表格要重复表头，并标“续表”；宽表（如变量定义表、相关系数矩阵）可单独设横页。
- 描述统计表可并入 VIF 列；相关系数矩阵建议排成下三角，用表注统一说明显著性阈值，避免满屏星号挤坏列宽。
- 回归表的写法：
  - 列是模型，行是变量；
  - 系数保留 3 位小数并带星号，括号内是标准误（放下一行或按老师样例与系数同格，全文统一）；
  - 核心回归表尽量**完整列出控制变量系数**，列太多排不下时放进附录；
  - 表底写明固定效应（写“是/否”）、观测值、R²；
  - 表里不能出现程序写法（如 `ln_size`、`OLS`）和内部任务编号。

**插图**
- **控制总数**：正文精简到 **3–4 幅核心图**，每幅图下配 1–2 段解读；删掉凑数的描述分布图和汇报式配图。
- **研究框架图**：黑白极简线条（《管理世界》风格），只留变量名、箭头、假设编号，主效应用虚线框，不配花哨颜色、图标或大段小字。
- 图题放在**图的下方**，按“图1、图2……”编号；分图写成“图1a、图1b”。
- 图要紧跟在**第一次提到它**（如“见图1”）的那段话后面。
- 一页最多放两张图，两张图之间要有正文。
- 图、图题、注要在同一页。

## 目录

- 用 Word 的自动目录（引用 → 目录），一般列到**两级**标题即可，中圆点或点线引导。
- 改完正文后：右键目录 → 更新域 → 更新整个目录。
- 所有页码右对齐，排在同一条竖线上。

## 数字和符号

- 数值区间用“～”，例如 3～5；年份区间用“-”，例如 2020-2025。
- 千分位用空格，不用逗号，例如 25 631；四位数不加空格。
- 公式用 Word 自带的公式编辑器，序号靠右；变量名里不要用下划线。

## 参考文献

- 按 GB/T 7714-2015 格式。中文文献在前，按拼音排序；外文文献在后，按字母排序。
- 正文引用的文献和文末列表一一对应。

## 附录

- 先写“附录一”，单独一行、顶格左对齐；附录题名放在下一行，居中。
- 问卷全文、访谈提纲、补充表格都放在附录里。

## 排完后检查

导出 PDF 后逐页看一遍：

- 有没有连续三页以上全是表格；
- 有没有一页放了三张图，或两张图之间没有正文；
- 目录页码和实际页码是否一致；
- 页面底部有没有超过四分之一页的空白（摘要、目录、结语等另起页之前的那一页除外）；
- 全文搜一遍下划线 `_` 和 `^`，结果应该是 0；
- **最终版要在 Windows 电脑上打开检查一次**，Mac 上的替代字体到 Windows 上会变样。
